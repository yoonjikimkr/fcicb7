# 서울 생활인구 데이터 처리 구현 계획서

## 개요
2026년 1월 서울 생활인구 데이터를 성공적으로 불러와 Tidy 데이터(가지런한 데이터) 형식으로 변환하고, `seoul-pops` 프로젝트 폴더 구조를 체계적으로 정리했습니다.

## 📁 1. 폴더 구조 정리
파일 종류와 용도에 따라 다음과 같이 폴더를 분류했습니다.

- **`data/raw/`**: 원본 ZIP 파일 및 압축 해제된 원본 CSV 데이터 보관
- **`data/processed/`**: 최종 Tidy 데이터 및 행정동 매핑 정보 보관
- **`docs/`**: 데이터 스키마 명세서, 매뉴얼 PDF, 엑셀 문서 및 계획서 보관
- **`scripts/`**: 데이터 처리에 사용된 Python 스크립트 보관

## 🧹 2. Tidy 데이터 변환 (데이터 전처리)
연령/성별 컬럼이 가로로 펼쳐진 기존의 Wide format 데이터를 분석에 용이한 Tidy (Long) format으로 재구조화했습니다.

### 주요 전처리 단계:
- **행정동 코드 매핑**: 8자리 행정동 코드를 매핑 정보와 결합하여 '시군구명'과 '행정동명'을 추가했습니다.
- **데이터 멜팅 (Melting)**: 가로로 나열된 28개의 연령/성별 세그먼트 컬럼을 `gender(성별)`, `age_group(연령대)`, `pop_count(인구수)` 컬럼으로 통합했습니다.
- **데이터 정제**:
    - CSV 파일 끝의 빈 필드 처리
    - 원본 파일의 불필요한 헤더 행 건너뛰기
    - 조인 작업을 위한 데이터 타입 일치화
