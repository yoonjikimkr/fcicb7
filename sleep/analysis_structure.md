# 분석 목표 정의
## 비즈니스 질문

1. 어떤 성분 조합이 어떤 수면 니즈(입면·수면 유지·자연주의)에 가장 잘 맞는가?

2. 각 성분/조합 별로, 어떤 가격대·브랜드·제형이 높은 평점과 리뷰 수를 얻고 있는가?

3. 리뷰/텍스트에서 드러나는 수면 니즈와 불만(부작용, 의존성 우려 등)은 무엇인가?

4. 이걸 기반으로, 한국 시장에서 “멜라토닌 이후”를 노리는 차세대 수면 영양제 포트폴리오는 어떻게 설계해야 하는가?


## iHerb 수면 카테고리에서 수집할 필드
크롤링 시, 최소한 아래 컬럼들을 가져오는 걸 추천해.
- product_id (또는 URL slug)
- product_name
- brand_name
- price_krw (표시 통화 기준)
- list_price_krw, 할인율(가능하면)
- rating (별점)
- review_count
- subcategory / tag (Sleep Formulas, Melatonin, Magnesium, Valerian, Chamomile 등)
- ingredient_snippet (상세 페이지 요약 성분 문자열)
- servings_per_container, price_per_serving (가능하면 계산)
- badges/claims (Non-GMO, Vegan, Gluten Free, Non-habit forming 등)

이걸 기반으로 아래 3가지 레이어를 만든다는 느낌으로 가면 좋다:
1. 성분 레이어: 멜라토닌 / 마그네슘 / 허브 / 복합포뮬러
2. 퍼포먼스 레이어: 가격, 평점, 리뷰 수, 베스트셀러 여부
3. 텍스트 레이어: 리뷰/제품명에서 드러나는 니즈(입면, 수면 유지, 자연스러움, 부작용 우려 등)


## 분석 구조  (리포트 골격)
1. 카테고리·성분 Landscape

성분별 SKU 비중: 멜라토닌, 마그네슘, 5-HTP, 트립토판, 발레리안, 패션플라워, 카모마일, 카바, 복합 포뮬러.

제형별 비중: 캡슐, 타블렛, 가미, 파우더, 리퀴드, 티백 등.
​

질문:

“현재 iHerb 수면 카테고리는 멜라토닌에 과의존하고 있는가, 아니면 이미 대체 성분으로 다각화되고 있는가?”

2. 가격·평점·리뷰 기반 성과 분석

성분군별 평균 가격 / 가격 분포, mg당 가격(멜라토닌 mg, 마그네슘 mg 등).

성분군별 평균 평점, 리뷰 수 분포 → “고가이지만 신뢰 높은 포지션 vs 저가 대량 제품” 구분.

브랜드별 집중도(HHI): 상위 5개 브랜드가 수면 카테고리 리뷰/매출의 몇 % 차지하는지.

질문:

“프리미엄을 받을 수 있는 성분·제형 조합은 무엇인가?”

“신규 브랜드가 진입하기 좋은 빈 포인트(성분×가격대×제형 조합)는 어디인가?”

3. 리뷰 텍스트 기반 니즈·불만 구조

리뷰 토큰화 후, 성분군별로 자주 등장하는 키워드·bigram 추출

멜라토닌: “fall asleep faster”, “groggy”, “vivid dreams”, “dependence” 등
​

마그네슘: “stay asleep”, “relaxed muscles”, “calm”, “no side effects”
​

허브 계열: “natural”, “tea”, “taste”, “mild effect”
​

LDA / 토픽 모델링 or 클러스터링으로 주요 토픽 도출 → “입면 속도”, “수면 유지”, “자연주의/라이프스타일”, “부작용/불안” 등의 축 정의.
​

질문:

“소비자가 실제로 원하는 것은 ‘빨리 잠드는 것’ vs ‘깨지 않고 자는 것’ vs ‘자연스럽고 안전한 것’ 중 무엇인가?”

“부작용·의존성에 대한 언급은 어떤 성분에서 특히 많이 나오는가?”

4. 세그먼트 정의 & 타겟팅 전략

이전 대화에서 잡았던 것처럼 3세그먼트로 정리:

입면형(Quick Sleeper) – 멜라토닌 중심, 빠른 입면, 야근·시차 적응 니즈

수면 유지형(Deep Sleeper) – 마그네슘·GABA 중심, 새벽 각성·얕은 잠 개선

자연주의형(Natural Sleeper) – 발레리안·카모마일·패션플라워, 티·가미, 장기복용·웰니스 지향

각 세그먼트에 대해:

선호 성분/조합

허용 가능한 가격대

선호 제형

리뷰에서 자주 언급되는 “성공 경험”과 “실망 경험”

이 코드로 뽑고 나서, 리포트에서 꼭 넣으면 좋은 것
표 1 – 성분별 요약

main_active, n_products, avg_price, avg_rating, avg_reviews

“멜라토닌은 SKU는 많지만 평점 분산이 크다 / 마그네슘은 SKU 적지만 리뷰당 평점 안정적” 같은 식의 해석.

차트

성분별 평균 가격 vs 평균 평점 (버블크기=리뷰 수)

성분별 SKU 수 vs 연평균리뷰수 (카테고리 집중 vs 팬덤 강도)

텍스트 분석 결과

각 성분군 대표 키워드/토픽 3개씩 + 예시 문장 1–2개

“멜라토닌: ‘빠르게 잠듦’ + ‘다음날 몽롱’ / 마그네슘: ‘근육이완’ + ‘다음날 상쾌’ / 허브: ‘향·티’ + ‘부드러운 효과’” 같은 구조
