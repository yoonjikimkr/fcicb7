# Streamlit 대시보드 생성 프롬프트

당신은 네이버 API를 활용한 데이터 분석 및 시각화 전문가입니다. 아래 요구사항에 맞춰 Streamlit 대시보드 코드를 작성해주세요.

## 목표
사용자가 입력한 검색어(키워드)를 기반으로 네이버 쇼핑 트렌드, 상품 정보, 블로그 검색 결과를 수집하고, 이를 Plotly를 사용하여 시각화하는 대시보드를 만듭니다.

## 주요 기능 및 구성
1.  **설정 및 입력**:
    *   사이드바에서 네이버 API Client ID와 Client Secret을 입력받거나, 환경 변수/Secrets에서 로드합니다.
    *   분석할 검색어(예: 오메가3, 비타민D)를 입력받습니다.
    *   '데이터 수집 및 분석' 버튼을 누르면 API를 호출하여 데이터를 가져옵니다.

2.  **데이터 처리**:
    *   **쇼핑 트렌드 API**: `datalab/shopping/category/keywords` 엔드포인트를 사용하여 최근 1년간의 트렌드 데이터를 가져옵니다.
    *   **쇼핑 검색 API**: `search/shop` 엔드포인트를 사용하여 관련 상품 정보를 가져옵니다 (최대 100건).
    *   **블로그 검색 API**: `search/blog` 엔드포인트를 사용하여 관련 블로그 포스트를 가져옵니다 (최대 100건).
    *   가져온 데이터는 Pandas DataFrame으로 변환합니다.

3.  **시각화 (Plotly & Streamlit)**:
    *   **탭 구성**: '요약', '트렌드 분석', '상품 분석', '블로그 분석'
    *   **트렌드 분석**:
        *   일자별 검색 클릭 추이 (Line Chart)
    *   **상품 분석**:
        *   상품 가격 분포 (Histogram)
        *   키워드별 가격 비교 (Box Plot)
        *   주요 브랜드/제조사 TOP 10 (Bar Chart)
        *   쇼핑몰별 점유율 (Pie/Donut Chart)
        *   상품 데이터 테이블 (가격, 쇼핑몰, 이미지 등)
    *   **블로그 분석**:
        *   포스팅 날짜별 추이 (Bar Chart)
        *   블로그 데이터 테이블

4.  **배포 및 보안 설정**:
    *   **로컬 환경**: `.env` 파일에서 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`을 로드합니다 (`python-dotenv` 사용).
    *   **Streamlit Cloud 배포**: `st.secrets`를 사용하여 API 키를 안전하게 관리하는 코드를 포함시킵니다.
    *   코드 내에서 두 가지 방식을 모두 지원하도록 예외 처리를 해주세요.

## 출력물

*   `requirements.txt`: 필요한 라이브러리 목록.
