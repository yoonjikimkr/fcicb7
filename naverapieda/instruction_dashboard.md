# Streamlit 대시보드 구축 작업지시서

본 문서는 수집된 네이버 쇼핑 트렌드 및 검색 결과를 시각화하고 분석하기 위한 Streamlit 대시보드 구축 가이드입니다.

## 1. 프로젝트 개요
- **목표**: 사용자가 입력한 키워드에 대한 쇼핑 트렌드, 상품 정보, 블로그 반응을 시각적으로 비교 분석할 수 있는 웹 대시보드 구축.
- **주요 기술**: Python, Streamlit, Plotly, Pandas.

## 2. 주요 기능 및 요구사항

### A. 대시보드 구조
- **사이드바**: 
  - API 키 입력 (또는 환경변수 로드 확인)
  - 분석할 키워드 입력 (복수 입력 가능, 예: 오메가3, 비타민D)
  - 조회 기간 설정 (Date Picker)
  - 데이터 수집 버튼
- **메인 영역**:
  - 탭(Tab) 구성: `종합 분석`, `쇼핑 트렌드`, `상품 분석`, `블로그 반응`, `Raw Data`

### B. 시각화 및 EDA 요구사항 (최소 5개 표, 5개 그래프)

#### 1. 종합 분석 (Summary)
- **KPI 지표**: 기간 내 평균 클릭량, 등록 상품 수, 블로그 포스팅 수 등 주요 지표 표시 (st.metric).
- **데이터 요약 표**: 키워드별 주요 통계 비교 (평균 가격, 최저가, 최고가, 검색량 등).

#### 2. 쇼핑 트렌드 (Shopping Insight)
- **시계열 라인 차트 (Plotly)**: 일자별/주간별 키워드 클릭 추이 비교. (Zoom/Pan 기능 활용)
- **기기별/성별 비중 파이 차트**: (API 지원 시) 검색 사용자의 기기(PC/Mobile) 및 성별 비중.

#### 3. 상품 분석 (Shop Search)
- **가격 분포 히스토그램**: 상품 가격대별 빈도수 분포.
- **브랜드/제조사 바 차트**: 상위 노출 브랜드 또는 제조사 빈도수 TOP 10.
- **상품 가격 박스 플롯 (Box Plot)**: 키워드별 상품 가격의 최저/최고/중위값 분포 비교.
- **쇼핑몰 점유율 도넛 차트**: 상품이 등록된 주요 쇼핑몰(Mall Name) 점유율.
- **상품 리스트 표**: 이미지, 상품명, 가격, 쇼핑몰 정보를 포함한 데이터프레임 표시 (Link 연결).

#### 4. 블로그 반응 (Blog Search)
- **포스팅 날짜별 빈도 바 차트**: 최근 블로그 포스팅 생성 추이.
- **주요 연관어 워드클라우드** (옵션): 블로그 제목 및 설명(Description)에서 추출한 단어 시각화.
- **블로그 리스트 표**: 블로그 제목, 요약, 링크, 작성일 정보.

## 3. 기술적 고려사항
- **API 연동**: `main.py`의 수집 로직을 함수화하여 대시보드에서 실시간 호출 가능하도록 통합하거나, `dashboard.py` 내에 포함.
- **환경 변수 관리**:
  - 로컬 실행 시: `.env` 파일 로드.
  - Streamlit Cloud 배포 시: `st.secrets` 활용 (TOML 설정).
- **인터랙션**: 데이터가 없을 경우 사용자에게 알림 메시지 표시 (`st.warning`, `st.error`).

## 4. 파일 산출물
- `dashboard.py`: 대시보드 메인 소스 코드.
- `requirements.txt`: 필요한 라이브러리 목록 (설치: `uv pip install -r requirements.txt`)
