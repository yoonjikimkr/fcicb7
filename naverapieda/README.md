# Naver API Data Collection & Dashboard Project

This project collects shopping trend data from Naver API and visualizes it using a Streamlit dashboard.

## Folder Structure
- `naverapieda/docs/`: API documentation.
- `naverapieda/data/`: Collected CSV data.
- `naverapieda/main.py`: Data collection script.
- `naverapieda/instruction_shopping_trend.md`: Data collection instructions.

## Setup
1. Install uv and dependencies: `uv pip install -r requirements.txt`
2. Set up API keys in `.env` file:
   ```
   NAVER_CLIENT_ID=your_id
   NAVER_CLIENT_SECRET=your_secret
   ```
3. Run collection: `python main.py`
